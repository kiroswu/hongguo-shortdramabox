## 二、功能特性

### 1. 沉浸刷剧

- **高清播放** — 1080P 多档画质，即点即播，自动记忆播放进度，下次打开无缝续播
- **弹幕互动** — 内置弹幕引擎，支持一键开关与弹幕发送，一个人刷剧也有陪伴感
- **倍速播放** — 多档倍速自由切换，快速补剧、慢速细品两相宜
- **自动连播** — 看完当前集自动播放下一集，刷剧不间断
- **小窗模式** — 置顶小窗播放，工作娱乐一眼兼顾
- **隐私模式** — 无痕观看，不写入本地记录，个人隐私滴水不漏
- **摸鱼模式** — 一键切换伪装形态，配合全局快捷键随时唤起或隐藏，安心摸鱼不打扰

### 2. 发现好剧

- **全网搜索** — 聚合搜索能力，热门短剧一网打尽
- **排行榜** — 热播榜、新剧榜实时更新，第一时间掌握全网热度风向
- **分类频道** — 推荐、漫剧、真人剧等多频道浏览，快速定位下一部好剧

### 3. 追剧管理

- **本地记录** — 历史、收藏、点赞、追更、预约，数据仅存储于本地，隐私无忧
- **追更提醒** — 喜欢的新剧一键追更，更新动态及时掌握
- **开播预约** — 提前预约期待新剧，开播不再错过

### 4. 离线下载

- **MP4 下载** — 剧集一键下载为 MP4 文件，离线也能随时刷剧
- **批量缓存** — 整部剧一次搞定，下载任务统一管理

### 5. 贴心体验

- **任务托盘** — 关闭窗口自动收缩至系统托盘，播放不中断，随时一键唤回
- **设置记忆** — 画质、倍速、弹幕、窗口位置/尺寸等使用偏好自动记忆，下次打开即恢复
- **主题外观** — 深色 / 浅色主题切换，主题色/毛玻璃配置，跟随你的使用习惯

### 6. 高级功能
- **蜂巢服务** — 一键服务化，局域网内所有设备（电视、电脑、平板和手机）浏览器全功能看剧，互不干扰。家庭/公司装X神器！
- **网络代理** — 自定义网络代理配置，网络配置更随心

## 五、常见问题

**Q1：只有声音、但是没有画画**
需要本机安装HEVC视频扩展对H.265视频解码（推荐。[点击下载](https://github.com/kiroswu/hongguo-shortdramabox/releases#release-HEVC%E8%A7%86%E9%A2%91%E6%89%A9%E5%B1%95)），或者本软件设置中开启软件解码（默认关闭）。

**Q2：使用短剧盒需要安装吗？**
不需要。软件为绿色单文件程序，下载解压后直接运行即可，删除目录即彻底卸载，无任何残留。

**Q3：观看记录、收藏等数据会上传吗？**
不会。历史、收藏、点赞、追更、预约等数据全部保存在本地，软件不收集、不上传任何个人数据。

**Q4：播放卡顿如何处理？**
软件默认启用硬件解码。如遇有声音没画面或兼容性问题，可在设置中切换解码方式，或适当降低播放画质。

**Q5：短剧盒会开源完整源代码吗？**
完整源代码的开源正在考虑中，确定后将第一时间在本仓库公布，敬请期待。
